# PawsAndPills

A comprehensive medication manager for your entire household - humans AND pets - in one app.

## Features

- **Multiple Profiles**: Manage humans (adult, senior, elderly, child, baby, pregnant) and pets (dog, cat, rabbit, bird, hamster, fish, reptile, horse)
- **Medication Tracking**: Add medications with dose, frequency, schedule, stock count
- **Smart Reminders**: Local notifications at scheduled times, missed dose alerts
- **Drug Conflict Checking**: Warns about known drug interactions
- **Species-Specific Warnings**: Toxic medication alerts per pet species
- **Calendar View**: See all doses across all profiles
- **History Log**: Track taken, missed, skipped doses
- **Shopping List**: Low stock medication alerts
- **Multilingual**: English, Arabic (RTL), French, Spanish
- **Fully Offline**: All data stored locally in SQLite
- **PDF Export**: Export medication history for vet/doctor visits

## Tech Stack

- Flutter 3.19.6
- SQLite (sqflite)
- Material Design 3
- Google Mobile Ads
- Local Notifications
- Shared Preferences

## Setup

1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run`
